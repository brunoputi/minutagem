Conectar para editar posições

Necessário uma vez por computador. A chave fica salva só neste navegador e permite alterar apenas este repositório.

  1. No GitHub, abra Settings → Developer settings → Personal access tokens → Fine-grained tokens e clique em Generate new token.
  2. Em Repository access, escolha Only select repositories e marque minutagem.
  3. Em Permissions, dê Read and write para Contents e para Actions.
  4. Gere a chave, copie e cole abaixo.
